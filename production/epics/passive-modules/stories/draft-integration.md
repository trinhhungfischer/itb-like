# Draft Integration (Passive Modules)

**Description:** Add Passive Modules to the Draft / Loadout Meta system reward pools, respecting rarity weights and incompatibilities.

## Acceptance Criteria
1. Passive Modules can drop from Reward nodes (Common/Uncommon), Elite rewards (Uncommon/Rare), Boss rewards (Rare), and Shops.
2. The drop pool respects the rarity weights defined in the GDD.
3. Incompatible modules (e.g., Hazard Walker and Acid Walker) cannot be equipped together.
4. Players can select and equip a drafted module to a hero's Equipment slot during the draft phase.

**Story Type:** Integration
**Story Points:** 2
**Dependencies:** Category Effects Implementation
