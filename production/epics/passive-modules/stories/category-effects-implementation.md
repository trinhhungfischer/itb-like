# Category Effects Implementation

**Description:** Implement the actual rule modifications for the 14 passive modules across Combat, Tactical, Survival, and Utility categories.

## Acceptance Criteria
1. Combat category modules (Force Amplifier, Piercing Strikes, Aftershock, Chain Reaction) correctly modify damage or spawn hazards/pushes.
2. Tactical category modules (Pathfinder, Overwatch, Warp Beacon) correctly modify movement, range, or provide teleport options.
3. Survival category modules (Kinetic Armor, Hazard Walker, Acid Walker, Last Stand) correctly grant immunities or prevent death.
4. Utility category modules (Scavenger, Spotter) correctly boost economy or reveal intents on hover/targeting.
5. Move Preview correctly reflects these rule changes where applicable (e.g., doubled collision damage, fire trails).

**Story Type:** Logic
**Story Points:** 8
**Dependencies:** Trigger Type Implementations
