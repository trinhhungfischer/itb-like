## Overview
Scope: Passive Module system — schema, equip logic, 2 hybrid Equipment slots, trigger resolution (OnAction/OnHit/OnKill/OnTurnStart), integration with Combat Resolution events. 
Provides 14 passive modules across 4 categories (Combat, Tactical, Survival, Utility). Each hero gets 2 Equipment slots which can be filled with either passives or gadgets.
