# Archetype Ability Definitions

**Description:** Create the `AbilityDefinition` data for all 11 enemy archetypes (Approach, Artillery, Zone, Support, Boss) ensuring they compile into Combat Resolution primitives.

## Acceptance Criteria
1. All 11 enemy archetypes are defined as units with correct shapes, `moveRange`, and `attackRange`.
2. All enemy abilities (Bite, Charge Strike, Slash, Acid Glob, Spike Shot, Mine Layer, Spawn Brood, Erect Wall, etc.) are implemented as `AbilityDefinition`s.
3. F1 Nearest-Threat targeting works correctly for these abilities.
4. The telegraph accurately represents the intended effect area and outcome.

**Story Type:** Content
**Story Points:** 5
**Dependencies:** None
