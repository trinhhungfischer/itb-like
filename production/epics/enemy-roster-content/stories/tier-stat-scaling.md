# Tier Stat Scaling

**Description:** Implement the 3 difficulty tiers (T1, T2, T3) for each archetype, scaling stats and expanding abilities as defined in the GDD.

## Acceptance Criteria
1. Enemies have T1, T2, and T3 variants.
2. T2 and T3 variants correctly apply HP, moveRange, and attackRange stat increases.
3. T2 and T3 variants correctly apply their expanded ability effects (e.g., T2 Charger adds 1-tile push, T3 adds 2-tile push; T3 Lobber adds Acid hazard).
4. Higher-tier enemies are correctly surfaced to the Encounter Generator based on run difficulty.

**Story Type:** Content
**Story Points:** 3
**Dependencies:** Archetype Ability Definitions
